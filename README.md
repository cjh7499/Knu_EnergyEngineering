# Knu_EnergyEngineering
1. 신재생 에너지란?
   
   신재생에너지는 탄소 배출을 최소화할 수 있으며 그 원천이 고갈되지 않는 다양한 자연 에너지의 특성과 이용기술을 활용하여 기존 에너지 발전을 대체하는 재생 가능한 에너지입니다.
   또한, 신재생에너지 분야는 기계, 화학공학, 전기, 전자, 재료, 물리, 자원 등의 여러 분야에 연관된 학제간 융합학문 분야입니다.

   본 학부에서는 태양광, 수소를 비롯한 신재생에너지 생산 관련 내용 및 생산된 신재생에너지의 효율적 활용을 위해 에너지 저장 장치에 저장하는 화학적 에너지 저장 기술(리튬 이온 전지 등)에 대하여 교육 및 연구합니다.
